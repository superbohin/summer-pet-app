本轮访问检查命令：

```sh
node --env-file=.env.local scripts/check-cloudbase-access.mjs
```

它仅创建匿名登录会话并请求健康接口，不读取或写入家庭业务表。只要正向调用未通过，
就返回非零退出码；不能把所有请求都被拒绝当成配置成功。输出不包含 Key 或会话令牌。
